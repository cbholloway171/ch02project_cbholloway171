Building HTML Lists

embedded style sheet
A block of CSS rules placed inside a <style> tag within the <head> section of an HTML document, applying styles locally to that single page.
external style sheet
A standalone .css file containing CSS rules that is linked to one or more HTML documents using a <link> tag in the <head> section.
inline style
CSS rules applied directly to a specific HTML element using the style attribute on that individual tag.

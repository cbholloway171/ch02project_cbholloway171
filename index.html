Building HTML Lists

embedded style sheet
A style sheet written inside a <style> element in the head of an HTML document; it applies only to that one page.
external style sheet
A separate .css file linked to an HTML document with a <link> element; it can apply the same styles to multiple pages.
inline style
CSS added directly to a single element using the style attribute; it applies only to that one element.
